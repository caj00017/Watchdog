## Reproducibility

A second independent build used a fresh `git archive`, fresh container process,
the same digest-pinned Python 3.12 base, exact locks, fixed epoch, and checked-in
sdist normalizer. The independently rebuilt wheel and source distribution were
byte-identical to the candidate and reproduced both SHA-256 values above.

The first pre-candidate experiment had exposed non-deterministic generated sdist
timestamps and ownership metadata. That experiment failed the gate and was not
retained as the candidate. The bounded normalizer and its fail-closed regression
tests corrected the issue before this record was produced.
