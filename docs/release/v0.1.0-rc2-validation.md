SIGTERM traverse application teardown and the workflow cleanup barrier.
SIGKILL, OOM termination, host or kernel loss, catastrophic interpreter
failure, and equivalent uncatchable termination cannot guarantee in-process
cleanup and were not represented as verified.

candidate preparation. No tag, push, GitHub release, package upload, registry
